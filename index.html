O vocabulário

As peças do jogo.

Seis ideias simples formam a base de quase todo projeto no GitHub.

01 / 06
◈

Repositório

A casa do seu projeto: código, arquivos, histórico e tudo que a equipe precisa para construir junto.

02 / 06
◌

Commit

Um ponto salvo na história. Cada commit registra uma mudança com contexto e uma mensagem clara.

03 / 06
⑂

Branch

Uma linha de trabalho independente para experimentar, corrigir ou desenvolver sem quebrar o principal.

04 / 06
↗

Pull Request

O convite para revisar e integrar suas mudanças. Conversa, feedback e qualidade antes do merge.

05 / 06
✓

Issue

Um espaço para organizar tarefas, bugs e ideias, transformando conversa em trabalho visível.

06 / 06
●

Clone & Push

Clone traz o repositório para sua máquina. Push envia suas novas versões de volta para a nuvem.
