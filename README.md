# projeto-github

Projeto desenvolvido durante o Workshop GitHub da COTI Informática.

Este repositório contém uma aplicação simples em HTML, CSS e JavaScript criada para práticas e exercícios durante o workshop.

## Sobre

O objetivo deste projeto é demonstrar conceitos básicos de desenvolvimento web (estrutura HTML, estilos com CSS e comportamento com JavaScript) e praticar uso do Git/GitHub.

## Tecnologias usadas

- HTML
- CSS
- JavaScript

Possíveis pastas do projeto:
- `index.html` — página principal
- `css/` — arquivos de estilo
- `js/` — scripts JavaScript
- `assets/` — imagens e outros recursos

(Se o seu projeto usar uma organização diferente, adapte os nomes das pastas acima.)

## Como abrir e rodar o projeto no VS Code

1. Clone o repositório para sua máquina:

   git clone https://github.com/Flipviduani/projeto-github.git

2. Abra a pasta do projeto no Visual Studio Code:

   - Abra o VS Code, vá em `File` → `Open Folder...` e selecione a pasta `projeto-github`.
   - Ou use o terminal do seu sistema dentro da pasta do projeto e execute `code .` (se o comando `code` estiver disponível).

3. Abrir a página HTML no navegador:

   Opção recomendada — extensão Live Server (recomendado):
   - Instale a extensão "Live Server" (de Ritwick Dey) no VS Code.
   - Abra o arquivo `index.html` no editor.
   - Clique com o botão direito no editor e selecione "Open with Live Server" ou clique no botão "Go Live" na barra inferior.
   - O Live Server abrirá o projeto em um navegador e recarregará automaticamente ao salvar alterações.

   Opção alternativa — abrir diretamente no navegador:
   - Localize `index.html` no explorador de arquivos e dê um duplo clique para abrir no navegador padrão.
   - Essa opção funciona, mas não força recarga automática ao salvar.

   Opção para servidor local (se preferir usar um servidor simples):
   - Com Python instalado, abra o terminal na pasta do projeto e rode:
     - Python 3: `python -m http.server 8000`
   - Abra `http://localhost:8000` no navegador.

4. Editar e testar

   - Faça alterações nos arquivos HTML/CSS/JS no VS Code.
   - Se estiver usando Live Server, o navegador será atualizado automaticamente ao salvar.

## Contribuições

Alterações simples e melhorias são bem-vindas. Para contribuir:

- Crie uma branch nova: `git checkout -b minha-melhoria`
- Faça commits com mensagens descritivas: `git commit -m "Descrição da mudança"`
- Envie a branch ao repositório remoto: `git push origin minha-melhoria`
- Abra um Pull Request no GitHub.
